# i18n

Official VerasJuris UI locales (formalized in `apps/web/src/lib/i18n/locales.ts`):

`pt-BR`, `en-US`, `es-ES`.

All three are LTR. Legacy preferences (for example `pt-PT`, `en-GB`, `es-MX`) normalize to the nearest official locale when possible; unsupported languages fall back to `pt-BR`.

**Resolution order:** user → org → `localStorage` (`vj.locale`) → browser → `pt-BR`.

**Catalogs:** JSON sources of truth under `apps/web/src/lib/i18n/messages/{pt-BR,en-US,es-ES}.json` (`pt-BR.json` is the key baseline). Typed loaders and helpers live in `apps/web/src/lib/i18n/` (`catalogs.ts`, `translate.ts`, `coverage.ts`); `apps/web/src/lib/i18n.ts` re-exports for compatibility.

Anonymous users always persist the chosen locale to `localStorage`. Authenticated preference sync still uses `PATCH /account/profile` when available.

Coverage: every official locale must contain 100% of `pt-BR` keys (see `i18n.coverage.test.ts`).

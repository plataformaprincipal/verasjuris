# i18n

Canonical first list of **30** BCP-47 locales (formalized in `apps/web/src/lib/i18n/locales.ts`; no prior 30-language list existed in the repo):

`pt-BR`, `pt-PT`, `en-US`, `en-GB`, `es-ES`, `es-MX`, `es-AR`, `fr-FR`, `de-DE`, `it-IT`, `nl-NL`, `pl-PL`, `ro-RO`, `uk-UA`, `ru-RU`, `tr-TR`, `ar-SA`, `he-IL`, `fa-IR`, `hi-IN`, `bn-BD`, `id-ID`, `ms-MY`, `th-TH`, `vi-VN`, `ja-JP`, `ko-KR`, `zh-CN`, `zh-TW`, `sv-SE`.

RTL: `ar-SA`, `he-IL`, `fa-IR`.

**Resolution order:** user → org → `localStorage` (`vj.locale`) → browser → `pt-BR`.

**Catalogs:** JSON sources of truth under `apps/web/src/lib/i18n/messages/*.json` (`pt-BR.json` is the key baseline). Typed loaders and helpers live in `apps/web/src/lib/i18n/` (`catalogs.ts`, `translate.ts`, `coverage.ts`); `apps/web/src/lib/i18n.ts` re-exports for compatibility.

Anonymous users always persist the chosen locale to `localStorage`. Authenticated preference sync still uses `PATCH /account/profile` when available.
